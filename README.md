This folder contains C programs organized by topic for better understanding and focused learning. Each subfolder targets a specific concept with multiple practical examples. Ideal for beginners and intermediate learners looking to strengthen their C programming skills.

# Topics Included:

Array – One-dimensional and multi-dimensional arrays, basic operations

Conditional_Statement – if, if-else, nested if, switch-case examples

Function – User-defined functions, recursion, function calling techniques

Homework – Practice assignments and exercises to reinforce learning

InterviewQoperaters – Operator-based C questions frequently asked in interviews

InterviewQvariable – Variable-related interview questions and tricky examples

Loops – Programs using for, while, and do-while loops

Operators – Arithmetic, relational, logical, bitwise, and assignment operators

Pointer – Pointer basics, pointer with arrays/functions, pointer arithmetic

Printf & Scanf – Formatted input and output, format specifiers, tricks

String – String manipulation, built-in functions, comparison, and reversal

Variable – Declaring, initializing, and understanding variable scope and types

# How to Use:
Open any topic folder to explore relevant C programs. All files are named meaningfully for easier understanding. You can compile any program using a standard C compiler (like GCC).
